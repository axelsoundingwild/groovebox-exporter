# Groovebox Exporter

Installers for **Groovebox Exporter**, by Axel Wild: turns a Novation Circuit Rhythm card into REAPER and Ableton Live projects.

Download the latest version from the [Releases](../../releases/latest) page, or from **[axelwild.com/grooveboxexporter](https://axelwild.com/grooveboxexporter)**, where you'll also find the install steps and how to get a licence.

This repository only holds the installers; the app needs a licence to run.
